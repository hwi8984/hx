## 사람용 5줄 (완전한 문장, 번호 대신 말, 숫자 앞뒤 띄어쓰기. 사용자는 이 5줄만 읽는다)
1. 무엇을 어떻게 다시 셌나: (만든 코드를 쓰지 않고 원본 ○행을 직접 읽어 ○○ 방식으로 ○○을 다시 셌다)
2. 같았나: (핵심 숫자 ○개 차이 0 / 다른 것 ○개)
3. 잡은 것: (FAIL 내용과 어느 숫자가 얼마나 달랐나 / 없으면 "없음")
4. 반론 2개: ("…해야 한다" → 받아들임/안 받음, 이유 한 줄, 받아들이면 숫자 ○ → ○)
5. 못 돌린 것: (NOT_RUN 과 이유)
